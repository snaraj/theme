# theme

[![release](https://img.shields.io/github/v/release/snaraj/theme?include_prereleases)](https://github.com/snaraj/theme/releases)

One command that owns the desktop wallpaper and the terminal palette
together, so they always agree.

This repository is the standalone home of the `theme` CLI, currently being
split out of [snaraj/dotfiles](https://github.com/snaraj/dotfiles) (where it
lives at `theme/` — `theme.sh`, its boundary-test fixture, and full docs).
Content migration lands via pull request; until then, the dotfiles copy is
the live one.
